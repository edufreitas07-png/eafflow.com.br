Dúvidas frequentes

Como eu recebo o acesso?

Depois que o pagamento é confirmado, enviamos o link das aulas e dos materiais para o e-mail e o WhatsApp que você informou.

Preciso saber programar?

Não. Quem escreve o código é o Claude. Você escolhe um prompt pronto, troca os dados e envia.

Funciona só pelo celular?

Sim. O curso inteiro foi pensado para ser feito no celular, sem computador.

Preciso pagar alguma coisa além do curso?

Não para criar e publicar: as contas usadas no curso são gratuitas. O plano gratuito do Claude tem limite de uso por período, então, se o limite acabar, é só esperar liberar. Domínio próprio (como .com.br) é opcional e pago à parte; o site funciona com o endereço grátis do Netlify.

Pagou e o acesso não chegou?
